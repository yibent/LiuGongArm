# BusAgent 实际功能接入（2026-09-05）

保留现有 Web 布局；新增功能由对话下达，不增加相机画面和模式选择。

## 可尝试的指令

- “桌上有哪些物品？”：返回固定相机当前可见候选，不是场景生成清单；来源为 Isaac 语义像素与 RGB 颜色，不代表任意实物识别或可抓取性保证。
- “记住这个红色方块，叫零件A。”：重新定位后保存对应采集帧的外观；不把坐标存成下一次动作目标。
- “记住了哪些物体？”、“找到零件A。”、“删除零件A的记忆。”
- “把零件A上方十厘米作为目标位置。”：重新视觉定位后执行。
- “复位，然后打开夹爪。”：最多四个明确原子动作依次执行；任一步失败、未知或停止，不继续剩余步骤。同一机械臂不宣称同时驱动。
- “抓起红色方块。”：实际定位 → 光流分段粗接近 → 新腕部 RGB-D 身份核对 → 原 FineGrasp → 夹持与抬升验证。

新流程使用同事的 `CoarseApproach`、LK、GraspGenX/FineGrasp 与相机安装配置。固定相机采用标签抓取入口的斜俯视安装，腕部采用 `fine_grasp` 默认安装。保留主场景物品，不创建 demo 物体，不传送关节。

定位模型的 HTTP 等待在工作线程进行，Kit 主线程继续更新并响应取消。实际相机读取、关节操作和清理仍只在 Kit 线程进行。粗接近 `execution_guard` 必须透传至真实执行器。

## 交互约束

聊天与理解/执行并行。聊天模型 reasoning=none，语义理解 reasoning=low；进度与结果仍由 LLM 根据当前事件简短表述。沿用句号切分 TTS 和 1.15 语速。

多步任务使用任务ID、步骤ID和独立控制器命令ID；中间步骤完成不发布整组完成，迟到旧步骤事件不覆盖新步骤。物体相对坐标在取得执行车道后才计算，避免排队期间过期。

新抓取先尝试一次，失败后仅在控制器明确提供有效重试或准备建议时询问用户。回准备姿态不自动抓取；取消清除剩余动作，不恢复旧授权。

## 服务

- 5173：当前前端构建，通过 SSH 隧道访问。
- 3100：BusAgent 后端；前端代理 `/v1/stt` WebSocket 与 `/v1/robot`。
- 7861：Isaac 控制接口。
- 5570：`scripts/serve_semantic_locator.py`，独立视觉 Python 环境，离线加载现有 Florence/YOLOE 权重；仅 localhost。
- 5556：现有 GraspGenX 服务，禁止自动几何抓取 fallback。

启动独立视觉服务时不能继承 Kit 的 `PYTHONHOME/PYTHONPATH/LD_LIBRARY_PATH`，否则可能混用 Python ABI。

前端在本地 `BusAgent/frontend` 执行 `pnpm build`，将完整 `dist/` 同步到服务器后，
从项目目录运行 `BUSAGENT_NODE_BIN=/root/gpufree-data/tools/node/bin/node bash scripts/run_web_frontend.sh`。
此入口通过 Vite preview 提供已构建页面，供当前 GPU 联调使用；代理固定默认到后端 3100，
并严格占用 5173，避免误连远程桌面的 3000 端口。不要在只部署了构建产物的服务器恢复
`vite` 开发模式：它会重新编译源码并要求完整的 lucide-react、Tailwind 等开发依赖。
恢复后应检查页面实际脚本/CSS、`/v1/robot/status` 和 `/v1/stt` WebSocket，不能仅检查 HTML 返回 200。

## 未实现的边界

放置、搬运到料格、任意长任务和自主无限重试未接入；不将“打开夹爪”伪装成已验证放置。绿色方块仍是控制标记。多目标抓取需明确单个目标。当前视觉记忆不保证在多个同类实例中唯一识别，歧义时停止并询问。模拟场景成功不代表真机或通用抓取验收。
