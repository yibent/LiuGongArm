## 指标不能直接沿用

报告第 23–25 页将指标归于参赛 PPT：mAP50:95 0.87、62 FPS、95.5% 入格、87% 自主恢复、11.9 秒周期，以及 VLA/路由消融。当前已提供的代码与回归不足以复算这些结果，不能标为本轮 Arena 实测。保留其原始配置与出处，待取得对应数据、模型、样本数和统计脚本后再核验。

本轮可核实的 Arena 记录在 `docs/arena/validation.json`：网页红方块执行 17.28 秒、圆柱快速抓放 17.69 秒；两项明确故障注入分别验证重新抓取、持物仅增强放置。它们不是工业成功率。当前 AnyPlace 20 候选、50 次迭代的服务 `inference_s` 约 6.3 秒，与报告约 0.1 秒的配置/计时边界尚未对齐。

## 按已确定的新架构推进

1. 首先恢复真实图像入口：复用 Florence / YOLOE / LK / SAM2 现有组件，统一输出实例 mask、身份、相机/帧引用和置信依据，替换 Arena 当前的目标真值掩码。
2. 补 SAM3 共享服务、图像点选、云端视觉回退和视觉记忆回写；按失败/不确定性触发，不把所有模型每帧串行运行。
3. 增加十二格与多工业物体场景、占用状态、完整的错放/掉落/倾倒恢复；主动观察由 Arena 负责执行，复杂路径接成熟规划能力。
4. 准备可复算的数据、微调与评测，再推进 RK3588、多臂和真机。M2T2 端侧、VLA、FLE 属于后续可选能力，不是当前官方快速抓放的前置条件。

本次没有根据报告增加运行限制，也没有启动模型迁移；这是现状与缺口核对。
