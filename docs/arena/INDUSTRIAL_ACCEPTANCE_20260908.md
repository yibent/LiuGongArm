# 2026-09-08 工业场景自主验收

验收要求：从自然语言入口识别最多来料区域，闭口实心端朝上装入分格料箱，处理倒置及已有横倒件，失败后自主恢复，装满后搬到高台另一只料箱上叠放。

测试使用云端实际 BusAgent、Gemini、YOLOE/SAM3/SAM2、Isaac Sim 和 Panda。不是 mock，也不向规划器提供物体资产名称、预选目标框或仿真真值。独立评测读取的 workspace 只用于记录和事后核对。现有缩小场景为三个来料区域 2/5/3 件、一个箱内横倒件、六格可移动料箱与高台上的第二只料箱；不是官方照片的完整规模和多执行器验收。

每轮前恢复初始布局；轮内不重置、不传送物体、不由测试者指定抓放对象。原有任务保持非活动状态，仅恢复新测试目标。自动监督启用。不同轮次之间的修复/重置不能计作 Agent 自主恢复。

## 第一轮：修改前真实失败

证据：`output/industrial-acceptance/20260908-full-1/`，会话 `industrial-acceptance-e2b72b46b3f6`。

- 约 38 秒提交第一阶段计划。实际集合观察分出了 5/3/2 的来料组，也找到箱内横倒件；另有一处误检，不能说整张清单完全准确。
- 初始 grasp 的 target 是裸 `obs:…` 字符串。执行解析将其当作文本标签，YOLOE/SAM3 实际收到整条引用作为类别，返回未找到目标。
- 本地恢复也把引用用作 category。监督误判为旧引用过期，重复框选后继续提交相同错误形式。朝向参数被放在顶层 `axis_ref/endpoint_direction`，而执行接口只读取 `orientation` 对象；抓取前的朝向传递机制因此没有获得约束。
- 230.685 秒后系统自主 blocked，26 次规划/视觉选择/监督模型调用，4 次抓取命令都在定位阶段失败，4 次补充感知失败，没有真正抓起或放置零件。
- 已返回的模型累计耗时：规划 26.171 秒、监督 117.810 秒、视觉选择 29.384 秒。对应输入 token 分别 40,477、112,463、6,632。这不包含对话模型，也不是账单金额或串行关键路径总耗时。
- 独立几何检查：正确入格 0/6，原横倒件未修复，料箱未搬运。

## 本轮修复及渠道验证

- 两个规划入口共享实际抓放参数说明；裸视觉引用转换成 `{ref}`，避免作为类别重新检测。
- 兼容此前输出的明确朝向字段并转换为 `orientation={axis_ref,endpoint,direction}`；缺少端点或冲突时在规划提交阶段指出具体格式问题，不能丢掉条件后执行。
- 抓放中执行器不支持的非空字段不再静默忽略。普通英文标签、任意对象选择和自由空位仍保留，未增加配置资产白名单。
- 提示词明确要求从同次观察图辨认端点，并在抓取前传朝向。已有“独立抓取→持物放置”前传约束机制继续使用。
- 第二轮 `20260908-full-2` 在 4.211 秒内因两渠道 HTTP 400 阻塞，未运动。原因是新增工具 schema 中的整数 enum；渠道返回 TYPE_STRING 错误。改为 integer minimum/maximum 后，对 Gemini 3.8 的真实工具请求返回 HTTP 200。这个失败是本轮实现引入的兼容问题，保留原始记录，不归因于账户无权限。
- 测试器增加只读持久队列查询，采集被网页执行列表隐藏的无动作规划失败，防止无意义等待。

参数交接修复后后端完整 335 项测试通过；渠道 schema 调整后另有 6 项针对性测试通过，最终完整回归 336 项通过，Nest 构建和本次后端文件 ESLint 通过。以上不是工业动作验收结论。

## 确定的断点与下一步

1. **动作参数交接断点已定位并部署修复，但没有新的物理成功验证。** 原视觉引用及朝向拼写错误可由真实失败输入和回归测试复现、修正；后续轮次被规划超时挡在动作前，不能宣布抓放整体已经修好。
2. **规划仍未能及时产出可执行阶段。** 第四轮读取过集合和料箱几何，压缩后又取回证据，两次请求的 JSON 路径不存在；随后重新读图，90 秒用尽仍无计划。这证实当前流程存在重复工具/检索成本；仅凭这些日志不能断言所有重复都由压缩算法引起。下一步需要保留选定对象、格位、端点及相应取回路径作为持续工作状态，并在预算耗尽前提交有依据的小阶段或明确缺失项，避免从观察重新开始。
3. **两渠道回退仍会占用主要响应时间。** 本轮实际出现主备各等 20 秒后一起失败，亦出现主超时、备成功。需要对耗时做请求级分账，将渠道故障与参数错误、证据缺失分别处理；不能仅增加超时阈值或让监督重复整个任务。
4. **未执行到的后段仍是未验收。** 本轮未完成连续装满、倒置件翻正、满箱搬运、叠放或搬运掉件恢复，不能从前端状态或单元测试推断它们通过。也没有绕过 BusAgent 由测试者指定框和姿态来补作“成功”。

结束现场：队列 paused=true，活动目标 0；Arena idle、command_id=null、held_object=null。场景保留初始工业布局，原有任务记录未删除。仅维护时重启 BusAgent，Arena 进程保持运行。
