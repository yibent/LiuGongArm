# BusAgent 独立推理节点与可检索上下文

2026-09-07。本次实现对应 [Q8 根因复盘](Q8_ROOT_CAUSE_REVIEW.md) 中的调度、状态续接、局部恢复和上下文问题。监督 LLM 保持关闭，模型与密钥不变。

## 已替换的运行逻辑

`robot.intelligence` 管理持久队列和动作账本。`robot.planning` 与 `robot.supervision` 是独立注册的 Bus 消费者，分别接收 `planning.requested`、`supervision.requested`；独立提示词、工具集合、模型上下文和提交契约，公共代码仅复用工具执行。

规划节点通过 `submit_plan` 同时给出方案与动作，直接落队列。`plan_scope=complete` 的有限方案在步骤验证成功后结束；`stage` 在阶段边界请求规划节点继续。正常推进不再依赖监督节点。监督节点只通过 `submit_review` 提交核验/修复意见，不能管理其他任务或调用规划提交工具。推理请求和返回携带请求 ID、目标版本和节点身份，过期响应不覆盖当前队列；落队列失败会转入可恢复的 blocked，避免永远停在 planning。

### 场景状态与恢复

- 单目标、集合观察和抓放结果共同更新 `ObservedScene`。对象有稳定 `object_id`，视觉引用是每次观察的证据；夹持、释放待确认、已放置和未知状态分开保存。
- 多个候选不能仅因标签相同而合并；密集场景位置关联不唯一时保留候选。已夹持物体不能留在旧桌面位置与另一个零件关联。
- 当前深度重新确认容器几何后，保留既有格位身份，并生成当前相机的引用。容器移动或几何不能确认时不沿用旧编号。这尚不是任意移动容器的完整姿态跟踪。
- 删除视觉服务内重复的旧格网记忆；跨观察保留统一由 `ObservedScene` 负责。云端换相机测试发现旧逻辑会把不在当前观察中的相机带回，导致 HTTP 500，已移除该冲突。
- 目标丢失、旧引用、抓空先尝试一次有新证据的定位；持物状态允许时从当前现场恢复。原动作与恢复记录保留，同一原因不无限重试。
- 已释放、物理检查成功但格位图像不确定时，只补充观察原格位；有稳定格位证据才继续。未解决的核验在监督关闭时等待人工处理。
- 当前抓法无法满足目标朝向返回 `REGRASP_REQUIRED` 并保持夹持，不再进入实际上相同的增强放置分支。通用暂放换抓技能仍待实现。

## 上下文机制

参考公开的 [Codex agent loop 说明](https://openai.com/index/unrolling-the-codex-agent-loop/)：固定提示和工具前缀、阈值压缩、保留工作状态及按需检索。这是适用于当前 Qwen/GLM 接口的本地实现；没有调用或复制 OpenAI 专属的 `/responses/compact` 不透明状态协议。

此前会话记忆虽有摘要，单次规划内部仍会累计重复工具结果、视觉候选和嵌套状态。本次对每一次模型请求实施预算：

1. 固定角色提示和工具定义；朝向、格位、集合等技能说明通过 `read_skill` 按需加载。
2. 原始目标、整体完成条件、当前队列和持物是工作上下文；监督不重复附带闲聊历史。集合使用成员引用，避免重复整份对象几何。
3. 完整工具结果先保存到按任务隔离的 `busagent_context_evidence`，仅将预算内的结构化预览放入模型输入。省略路径、原始引用和分页入口可通过 `read_evidence` 恢复；相同结果只回传引用和简要状态。
4. 超过预算的 85% 时，压缩旧的完整 assistant/tool 轮次，留下工具参数、结果状态和证据索引；保留原任务与最近轮次，避免拆散 tool-call 配对。已消费的旧图像在需要时退出上下文，原快照仍可读取。
5. 原始目标和最近证据仍放不下时明确报告预算不足，保留任务等待调整，不截断用户约束继续执行。

默认输入估算预算 12,000 tokens，单工具预览预算 1,600，可在前端智能设置修改。预算包含工具定义和文本；每张图暂以 2,048 tokens 预留，**不是厂商精确计费**。图像仍默认不读取。实际 API usage 与 `context_budget` 估算事件分别记录，不能将后者当作账单。未实现自动发现各提供商模型上下文上限。

证据归档当前不自动过期；后续需根据运行量配置保留期。会话历史继续使用原来的摘要与分页，新增明确的旧历史入口；本次没有假称具备 Codex 内部私有的全部记忆机制。

## 离线回放验证

固定同一段 Q8 `repair-6/repair.json` 工具证据，使用 9 轮桩模型回放。对照 BusAgent `c0ed3e7fc8149e15863d64ea373389ea400a77b3`，没有调用 Qwen 或发送机器人命令。

| 角色 | 旧累计输入估算 | 新累计输入估算 | 旧单次峰值 | 新单次峰值 |
| --- | ---: | ---: | ---: | ---: |
| 规划 | 204,501 | 79,076 | 31,416 | 9,779 |
| 监督 | 204,510 | 77,208 | 31,417 | 10,051 |

累计估算减少约 61.3% / 62.2%。此结果仅验证固定工具轨迹的载荷缩减，**不代表实际计费、模型决策质量或 Q8 自主成功率**。离线脚本：`BusAgent/backend/scripts/benchmark-intelligence-context.mjs`；先构建 backend，再传入 Q8 记录路径与输出路径。默认基线固定上述提交，第四个参数可替换基线。

验证覆盖：独立角色工具、阶段续接、关闭监督后复杂队列执行、过期/无效响应、持物续接、补充观察不重放动作、完整轮次压缩、证据检索分页、重复结果去重、图片预算、用户条件保留。Arena 回归覆盖多视角身份、持物生命周期、格位身份和换抓失败分类。
