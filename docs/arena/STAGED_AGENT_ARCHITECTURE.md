# BusAgent 阶段任务架构

系统设置中的 `Agent 架构` 可以在 `staged` 与 `legacy` 间切换。切换只影响新输入；已经建立的任务列表按创建时的架构继续执行。

`staged` 的一次输入按以下流程处理：

1. 最终语音文本同时进入即时对话节点和快速任务模型。
2. 快速任务模型只调用一次，返回 `no_action`、`query`、`simple`、`complex` 或 `modify`。
3. `no_action` 不创建执行列表；`simple` 在同一次响应中提交完整动作；`complex` 和 `modify` 再调用一次高级任务模型。
4. 高级模型生成带 `stage.id`、编号、依赖和可观察完成状态的动作序列。一抓一放优先表示为一个 `pick_place` 阶段。
5. 有依赖的阶段同步等待 Florence 局部检查；独立阶段继续执行，检查异步完成。失败阶段在限额内插回待执行队列，反复失败的独立阶段暂时跳过，有依赖阶段交回高级模型重新规划。
6. 列表结束后由独立复核模型集中检查一次。修复和复核次数都有硬上限。

模型渠道分别声明 `vision` 和 `boxGrounding`。只有两项都开启时，高级模型才可以输出绑定冻结截图的 `box_2d`；该框仍需 SAM2、深度和相机标定转换成可执行引用。未开启原生框选时，模型只输出开放词汇标签，定位链为 YOLOE → SAM3 → Florence，定位成功后使用 SAM2 和光流跟踪。

所有模型调用使用 OpenAI 兼容流式响应。快速任务和对话默认等待首字 8 秒；直接读图的高级规划、最终复核和视觉节点默认等待 30 秒，均可按节点或渠道覆盖。总超时不会短于首字等待。

每个模型节点可以选择 `disabled`、`same_capability` 或 `ordered_compatible` 回退策略。高级规划默认只切换到具备相同图像能力、以及所需框选能力的模型；图片请求不会降级成 Florence 描述加纯文本规划。高级模型不支持原生框选时仍可直接读取图片并输出开放词汇标签，后续定位由 YOLOE → SAM3 → Florence 完成。只有高级模型本身不支持图片时，才将本地视觉证据作为其文本输入。

`legacy` 保留原 Mastra 工具循环、旧任务恢复和原有路由，用于兼容既有任务及对照测试。
