# 在线速度、语音中断与抓取兼容修复（2026-09-05）

## 运动与渲染

- 普通机械臂轨迹：28.65 → 85.95 度/秒，最大加速度 60 → 540 度/秒²。
  五次平滑轨迹按时间缩放，峰值速度与加速度分别按 3 和 9 倍变化。
- 空载夹爪开合有独立速度配置；接触抓取仍由限力闭爪控制器负责。
- 保留导入的刚度与力矩限制；阻尼提高 50%，求解位置/速度迭代为 64/4。
- 轨迹同时下发解析速度前馈；终点、暂停、停止恢复零速度目标。
- 保留 1° 位置误差、1°/秒速度及连续 0.35 秒停稳判定，不跳过实际反馈。
- 物理 120 Hz，与桌面/相机 15 FPS 解耦，每次渲染包含 8 个物理小步。
  `IsaacGraspSession` 的阻塞适配器每次 `app.update()` 推进一个渲染周期，
  因此其步进预算使用渲染间隔，而不是单个物理子步间隔。

配置见 `configs/motion.yaml`、`configs/robot_so101.yaml`、`configs/cameras.yaml`。
`set_speed` 接口范围更新为 1–120 度/秒，并同时影响空载夹爪，避免后续用户调慢失效。
上述值用于本项目的 Isaac 仿真，不是实体 SO-101 的额定驱动参数。

最终服务器实测（含双相机与 GraspGenX 常驻）：空载夹爪到达 1° 开度容差用时
1.836 秒，包含停稳及 API 轮询的完整完成用时 2.864 秒；最大最终关节误差 0.092°。
停稳后约 1.5 秒的采样峰峰值小于 0.00001°。归位完成约 4.246 秒。
这是该次场景实测，不保证在任意 GPU 负载下精确等于 2 秒。
记录：`/root/gpufree-data/deploy-backups/gripper2s-RDFeXTQi/validation.json`。

调参依据：[NVIDIA 关节驱动调参说明](https://docs.isaacsim.omniverse.nvidia.com/latest/robot_setup/ext_isaacsim_robot_setup_gain_tuner.html)。

## 语音重复停止

根因：ASR 未提交尾部不断变化，原中断器按文本去重；普通片段又清除了去重状态，
同一句话触发多次停止。现在 STT 为一次合并语句发出稳定的 `utterance_id` 和完整
`hypothesis`，中断器每句只发一次即时停止，最终稿不会再重复。下一句话仍能再次停止。

完整语句继续交给语义模型理解，避免“停止，然后移到方块上方”丢失后半句。
TTS 在握手前取消也会释放等待中的写入，不把旧会话的迟到错误报告到新会话。
问候与能力询问同时出现时优先回答能力问题，能力以控制器实时列表为准。

## 抓取关联与实时位姿

1. Isaac 6 的 `attach_annotator` 把 `_fast` 后缀从公开帧键中移除。
   现在同时支持 `instance_segmentation` 和旧 `_fast` 键，仍用传感器像素关联实体，
   不按物体名字猜坐标。服务器已确认红方块、黄螺母对应 Block、NutM20 实体。
2. GPU/Fabric 仿真下 USD 连杆姿态可能仍是启动姿态。末端读取改成 Fabric 实时后端，
   相机读取对应 RGB-D 帧的渲染变换；不允许默默回退到 USD 静态姿态。
   实测 FK/物理位姿误差从约 323 mm 降到约 0.218 mm。
3. 相机侧向安装，固定观察偏航角可能把末端推到工作空间之外。现在在同一测量点上方
   枚举 12 个观察偏航角，仅经现有可达性规划确认后执行一个；不是几何抓取或失败重抓。

GraspGenX 仍是真实模型服务；超时或无候选不会自动切换几何后端。
实例关联或观察位姿验证通过，不等于抓取及抬升验证通过。
