# Industrial workbench geometry

Original procedural assets generated by `scripts/build_industrial_assets.py`, in metres, Z up. Regenerate with a Python containing `usd-core`, or Isaac Sim's Python. These files are scene construction data, not an execution catalogue. They contain no class tags, grasp poses or target aliases.

| File | Geometry |
| --- | --- |

| asset_02.usda | Silver hex nut with a through-hole |
| asset_03.usda | Orange spur gear with 16 teeth and a central bore |
| asset_04.usda | Steel stepped shaft |
| asset_05.usda | Brass hex-head bolt with thread ridges |
| asset_06.usda | Blue-green hollow sleeve |
| asset_07.usda | Dark washer |
| asset_08.usda | Blue open parts tray |
| asset_09.usda | Orange open parts tray |
| asset_10.usda | Fixture plate with pegs and a hook |

Each asset has one rigid root and multiple primitive/convex child colliders. Ring sectors preserve the physical opening instead of filling it with a single convex hull. Visual and friction materials are authored in USD. This follows Isaac Sim's [rigid body and collider composition](https://docs.isaacsim.omniverse.nvidia.com/latest/physics/simulation_fundamentals.html).

Load `configs/arena_panda_industrial.json` through Arena. Seven parts are dynamic; two trays and the fixture are kinematic. The scene includes a crowded nut/washer region and oblique part orientations. Pegs and the hook are test geometry; their presence does not mean insertion or hanging execution is implemented.
